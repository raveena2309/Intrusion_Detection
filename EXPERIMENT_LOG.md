### Log Format

Each experiment entry includes:
- **Experiment ID:** Unique identifier (E1, E2, ...)
- **Date:** Execution date
- **Phase:** Development phase
- **Dataset Split:** Train/test/validation details
- **Configuration:** Model parameters, random seed, software versions
- **Results:** Metrics and artifact paths
- **Notes:** Observations, issues, decisions
